1. RESUMEN EJECUTIVO
--------------------------------------------------------------------------------

Este estudio ha desarrollado e implementado un sistema híbrido que combina:
• Modelos de Machine Learning tradicionales (Random Forest, XGBoost, LightGBM)
• Modelos de Deep Learning (LSTM, GRU, CNN-LSTM)

• Detección automática de patrones chartistas

El sistema integra predicciones cuantitativas con análisis cualitativo para
tomar decisiones de inversión informadas.

8. CONCLUSIONES
--------------------------------------------------------------------------------

1. El sistema híbrido ML + LLM demuestra la viabilidad de combinar 
   predicciones cuantitativas con análisis cualitativo.

2. La detección automática de patrones chartistas proporciona señales
   adicionales para la toma de decisiones.

3. El sistema multi-agente permite una evaluación integral del mercado
   desde múltiples perspectivas (técnica, sentimental, riesgo).

4. Los resultados del backtest muestran retornos positivos pero con
   alta volatilidad, lo cual es esperado en estrategias de trading.

5. Limitaciones identificadas:
   - La predictibilidad del mercado es inherentemente limitada
   - Los modelos ML muestran R² negativo, indicando dificultad para
     predecir retornos exactos
   - Se requiere mayor optimización de hiperparámetros
